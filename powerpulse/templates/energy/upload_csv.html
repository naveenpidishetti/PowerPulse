Your CSV file must have column headers in the very first row. The columns can be in any order:

Header Required Sample Value
reading_date Required 2026-10-01
consumption_kwh Recommended 34.70
previous_reading Optional 10240.50
current_reading Optional 10275.20
tariff_per_unit Optional 8.50 (₹ INR)
building_name Optional Main Residence
Sample Raw CSV Lines:
reading_date,previous_reading,current_reading,consumption_kwh,tariff_per_unit,building_name
