v1.0.0 JSON RESTful API

PowerPulse Developer API

Programmatic access to electricity meter readings, bulk CSV ingestion, AI consumption forecasts, dual-layer anomaly detection, and billing audits.

Raw API Root (JSON) User Manual Guide
Base Endpoint
http://localhost:8000/api/ All requests return standard application/json payloads.
Authentication
Supports Session Cookie (automatic in browser), HTTP Basic Auth (admin:admin123), or zero-config sandbox fallback.
Standard Currency
All financial tariffs and estimated costs are standardized to Indian Rupee (₹ INR).

Available API Endpoints

GET /api/readings/ List Meter Readings
Try Live

Retrieve paginated electricity readings recorded by the user. Filterable by building name or date range.

Query Parameters
ParameterTypeDescription
limitintegerResults per page (default: 50)
offsetintegerStarting index (default: 0)
buildingstringFilter by building name
start_dateYYYY-MM-DDEarliest reading date
end_dateYYYY-MM-DDLatest reading date

POST /api/readings/ Log New Reading
Content-Type: application/json

Record a daily meter reading. The engine automatically calculates consumption (Current - Previous), computes cost at active tariff (₹), and runs anomaly evaluation.

Sample JSON Request Body
{
  "reading_date": "2026-11-15",
  "previous_reading": 16458.2,
  "current_reading": 16495.0,
  "tariff_per_unit": 8.50,
  "building_name": "HQ & Main Campus"
}
cURL Command Snippet
curl -X POST http://localhost:8000/api/readings/ \
  -H "Content-Type: application/json" \
  -u admin:admin123 \
  -d '{"reading_date":"2026-11-15","current_reading":16495.0,"previous_reading":16458.2,"tariff_per_unit":8.5}'
POST /api/readings/upload-csv/ Bulk CSV Ingestion
multipart/form-data

Upload and ingest dozens or hundreds of meter readings in a single API call.

cURL File Upload Command
curl -X POST http://localhost:8000/api/readings/upload-csv/ \
  -u admin:admin123 \
  -F "csv_file=@sample_meter_readings.csv"
200 OK Response
{
  "status": "success",
  "message": "Successfully ingested 31 readings from CSV",
  "created_count": 31,
  "errors_skipped": 0,
  "anomalies_detected": 2
}
GET /api/analytics/forecast/ Machine Learning Forecast
Try Live

Execute dynamic multi-step time-series forecasting. Supports rf (Random Forest Regressor) and ridge (Ridge Regression) across 7, 14, or 30 day horizons.

Parameters
  • horizon: Number of days forward (e.g. 7, 14, 30). Default: 7.
  • model: rf (Random Forest) or ridge (Ridge Regression). Default: rf.
Sample Output
{
  "status": "success",
  "model_name": "Random Forest Regressor",
  "horizon_days": 7,
  "rmse": 3.84,
  "mae": 2.91,
  "currency": "₹",
  "forecasts": [
    {"date": "2026-11-15", "predicted_kwh": 36.4, "estimated_cost": 309.4},
    {"date": "2026-11-16", "predicted_kwh": 37.1, "estimated_cost": 315.35}
  ]
}
